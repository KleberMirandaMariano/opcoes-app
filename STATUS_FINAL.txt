🔄 FLUXO DE DADOS
════════════════════════════════════════════════════════════════════════════

Navegador (http://localhost:3001)
    ↓
Express Backend (:3001)
    ├─ Tenta RB3 em localhost:3002 (timeout 5s)
    │  ├─ Responde? → DADOS REAIS ✅
    │  └─ Não responde? → DADOS MOCK ✅
    ├─ Cache (TTL 5 min)
    └─ JSON Response
        ↓
Frontend JavaScript
    └─ Renderiza HTML
        ↓
Usuário vê dados
(Indistinguível entre real e mock!)
