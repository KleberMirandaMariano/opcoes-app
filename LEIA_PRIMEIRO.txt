PROBLEMA:
---------
Você tentou rodar a API RB3 (em R) para pegar dados em tempo real da B3,
mas os scripts não funcionaram no Windows:

❌ "Rscript não é reconhecido"

SOLUÇÃO:
--------
Criei um sistema FALLBACK que:

✅ Tenta usar RB3 (dados reais da B3)
✅ Se RB3 não responder → usa dados MOCK automaticamente
✅ APP FUNCIONA SEMPRE (com ou sem R)
