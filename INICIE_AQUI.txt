💡 USANDO A API NO SEU CÓDIGO REACT
════════════════════════════════════════════════════════════════════════════

Importar:

    import apiService from './services/apiService';

Usar:

    // Buscar índices
    const indices = await apiService.getMarketIndices();

    // Buscar ações em alta
    const stocks = await apiService.getStocks('altas');

    // Buscar detalhes de uma ação
    const stock = await apiService.getStockDetail('PETR4');

    // Buscar histórico (últimos 30 dias)
    const history = await apiService.getStockHistory('PETR4', 30);

    // Analisar opção (preço, gregas)
    const analysis = await apiService.analyzeOption('PETR4', 30.00, 'call');


🆘 PROBLEMAS?
════════════════════════════════════════════════════════════════════════════

"npm: comando não encontrado"
→ Instale Node.js: https://nodejs.org/

"Backend não conecta"
→ Verifique se npm run dev foi executado
→ Veja se porta 3001 está disponível

"Vite proxy não funciona"
→ Reinicie: Ctrl+C e npm run dev novamente

"RB3 não responde"
→ Isso é normal! Backend usa dados mock automaticamente
→ Para dados reais, instale R + RB3 (veja documentação)

🎨 PERSONALIZAÇÕES
════════════════════════════════════════════════════════════════════════════

Mudar porta do frontend (3000):
  → Edite vite.config.ts, seção server.port

Mudar porta do backend (3001):
  → Edite backend/server.js, const PORT

Adicionar dados customizados:
  → Edite backend/services/rb3-fallback.js

Integrar com Gemini:
  → Já está configurado! Veja geminiService.ts

❓ PERGUNTAS FREQUENTES
════════════════════════════════════════════════════════════════════════════

P: Como atualizo os dados em tempo real?
R: Eles se atualizam automaticamente via cache com TTL 5 minutos.
   Dados vêm da B3 em tempo real (com fallback para mock).

P: Como adiciono mais ações?
R: Edite backend/services/rb3-fallback.js

P: Como faço para rodar só o backend?
R: npm run dev:backend

P: Preciso instalar R?
R: Não é obrigatório! Dados mock funcionam perfeitamente.
   Para RB3 real, veja documentação do opciones-app.

P: Posso usar em produção?
R: Sim! Está pronto. Só execute: npm run build
