├─ Porta: :3001
└─ Status: Responsivo, Multi-usuário

BACKEND (Node.js + Express)
├─ Localização: backend/server.js
├─ Middlewares: Express-session, Helmet, CORS
├─ Serviços: Providers, Logger, Validators
├─ Porta: :3001 (mesma do frontend)

   ├─ Isolamento multi-usuário
   ├─ Validação de entrada

RB3 CLIENT (Node.js)
├─ Localização: backend/services/rb3-client.js
├─ Responsabilidade: Conectar a RB3 ou fallback
├─ Timeout: 5 segundos
├─ Métodos:
   ├─ getIndices()

   ├─ getStocksList(filter)
   ├─ getStockHistory(ticker, days)
   └─ getStatus()
└─ Retorno: Dados reais OU mock

RB3 FALLBACK (Node.js) - NOVO!
├─ Localização: backend/services/rb3-fallback.js
├─ Responsabilidade: Fornecer dados mock
├─ Disponibilidade: Sempre (se RB3 falhar)
├─ Dados:
   ├─ 4 Índices (IBOV, IFIX, DOLAR, BTC)

├─ Cache: Local com TTL
└─ Performance: ~100ms

RB3 API (R/Plumber) - OPCIONAL
├─ Localização: rb3-api/app.R
├─ Framework: R + Plumber
├─ Porta: :3002
├─ Endpoints:
   ├─ GET /indices

   ├─ GET /stocks/list/{filter}

FLUXO DE REQUISIÇÃO DETALHADO:
════════════════════════════════════════════════════════════════════════════

1. Usuário acessa http://localhost:3001
   ↓
2. Frontend carrega (HTML + JS)
   ↓
3. JavaScript faz requisição: GET /api/market/indices
   ↓
4. Backend recebe em backend/routes/market.js
   ↓
5. Chama: rb3Client.getIndices()
   ↓
6. rb3Client testa: RB3 disponível?
   ├─ PING: http://localhost:3002/health (timeout 5s)
   │  ├─ ✅ Responde?
   │  │  └─ Busca em /indices
   │  │     └─ Retorna DADOS REAIS
   │  │
   │  └─ ❌ Timeout/Erro?
   │     └─ Chama rb3Fallback.getIndices()
   │        └─ Retorna DADOS MOCK
   │
7. Backend retorna JSON
   ↓
8. Frontend renderiza no HTML
   ↓
9. Usuário vê dados no navegador
   (Indistinguível entre real e mock!)

DECISÃO DE ROTEAMENTO (Lógica):
════════════════════════════════════════════════════════════════════════════

async function getIndices() {
  // 1. Verificar se RB3_ENABLED=true
  if (!RB3_ENABLED) {
    return rb3Fallback.getIndices(); // Força fallback
  }

  // 2. Tentar conectar RB3 (timeout 5s)
  const isAvailable = await isRB3Available();

  // 3. Se disponível, usar dados reais
  if (isAvailable) {
    const response = await fetch('http://localhost:3002/indices');
    if (response.ok) {
      return await response.json();
    }
  }

  // 4. Se não disponível ou erro, usar mock
  return rb3Fallback.getIndices();
}
